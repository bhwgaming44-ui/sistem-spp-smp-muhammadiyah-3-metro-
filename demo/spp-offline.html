📌 Agar bisa diakses tanpa laptop menyala
  1. Aplikasi harus di-upload ke hosting/VPS yang menyala 24 jam (Railway, Render, Hostinger, VPS, dll.).
  2. Siapkan database MySQL di hosting, lalu isi variabel DB_*.
  3. Set APP_ENV=production, APP_DEBUG=false, dan APP_URL=https://domain-anda.
  4. Jalankan migrasi database dan storage:link di server.
  5. Setelah dapat domain, simpan URL-nya di kolom di atas agar QR bisa dipakai.
  6. Ubah Webhook Midtrans ke https://domain-anda/api/midtrans/notification.
⚠️ Login aplikasi saat ini memakai akun demo di browser. Sebelum dipublikasikan, sebaiknya ganti dengan autentikasi server agar menu petugas tidak bisa dibuka sembarang orang.
